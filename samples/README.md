# VGR Samples

* `10print.vgr` - The [classic](https://10print.org) basic demonstration program
* `7segment.vgr` - Visual demonstration of using binary operations
* `array-test.vgr` - Demonstrates operations applied to arrays
* `basic-loops.vgr` - Examples of `While` and `Until` loops
* `begin-block.vgr` - Shows variable scoping within a `Begin/End` block
* `colors.vgr` - Demonstration of the `Terminal` statement's capabilities
* `comparison-tests.vgr` - Examples of the forms of comparison operators—ASCII, Typographic, English—and various forms of `Choose Using`
* `doc-gen.vgr` - Used to generate VGR samples included in documentation
* `encoding.vgr` - Demonstrates using character encoding and representing strings in hex and Base 64
* `eq-test.vgr` - Performs comparisons between data types
* `fib-basic.vgr` - Calculate Fibonacci numbers written in the style of BASIC
* `fib-c.vgr` - Calculate Fibonacci numbers written in the style of 'C'
* `fib-functions.vgr` - Calculate Fibonacci numbers using various functions, including one which caches results
* `fib.vgr` - Calculate Fibonacci numbers written in a "native" VGR style
* `hello-world.vgr` - The ur-sample
* `ldap.vgr` - Uses a public [LDAP server](https://www.forumsys.com/2022/05/10/online-ldap-test-server/) to demonstrate the `LDAP` statement
* `load-from-test.vgr` - Uses the `Load` statement to read in a file and searches for results using `LookupItem()`
* `log-parsing.vgr` - Demonstration of `ExtractMatch()` to identify and parse text
* `mail-merge.vgr` - Example of loading, sorting, and outputing data
* `main-1.vgr` and `main-2.vgr` - These two work together to demonstrate the `Source` statement and using the built-in `vgr` variables
* `mandelbrot-set.vgr` - A visual demonstration of using `Function`s and the `Terminal` statement
* `matches.vgr` - Demonstration of the flexibility of the `Matches` and `Does Not Match` operators
* `math-statements.vgr` - Examples of using the mathematical `Add`, `Subtract`, `Multiply`, and `Divide` statements
* `partition.vgr` - Implements Python's partition() and rpartition() in VGR functions
* `people.vgr` - Demonstrates the `Sort` and `Select` statements using a JSON data file
* `print-matricies.vgr` - Prints out matricies of math operations using functions. Demonstration of function as first class values
* `printing-test.vgr` - Examples of `Print` and `Printf` statement behavior
* `regex.vgr` - Demonstrates using regular expressions and the built-in patterns and values in the `re` variable
* `scan-function.vgr` - Implements the Excel [Scan()](https://support.microsoft.com/en-us/office/scan-function-d58dfd11-9969-4439-b2dc-e7062724de29) function using `CombineUsing()`
* `select.vgr` - Demonstrates the use of the `Select` statement
* `sse.vgr` - ASCII animation using the `Terminal` statement
* `string-functions.vgr` - Examples of string based functions used with various data types
* `superscripts.vgr` - Demonstrates using Unicode superscript characters to raise numbers to a power
* `time-check.vgr` - Example using `time.today` built-in, dynamic variable
* `type-conv.vgr` - Shows the results of using "To" functions to change data types
* `var-contexts.vgr` - Demonstration of using variable context prefixes
* `variable-names.vgr` - Examples of variable naming
* `vault-test-runner.vgr` - Work-in-progress...
* `version.vgr` - Defines a `RequiresVersion()` which can be added to scripts using  `@Include`
* `word-freq.vgr` - Interactive calculation of word frequency
* `write-markdown.vgr` - Example of using the built-in Markdown functions
